# 把你的资料放进这个目录

支持任意层级的子文件夹,自己按习惯组织,例如:

```
my local knowledge/
├── 产品资料/
├── 行业规范/
├── 竞品材料/
└── 培训学习/
```

## 重要:二进制文档要先提取

PDF / Word / PPT / Excel 里的文字**不能直接被搜索,AI 也读不了**。
放好文件后,到「知识库」页点 **「提取新增」**,工作台会把它们提取成可检索的纯文本
(存在 `knowledge/.extracted/`,不进版本库)。

提取完就可以:
- 全文搜索命中这些文档的内容
- AI 写方案时直接引用
- 点「编译 wiki」把资料编译成互链的知识页

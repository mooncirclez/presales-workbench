# 投标响应自检清单

## 何时使用
用户拿到招标文件(pdf/docx),要求"投标自检 / 响应检查 / 生成检查清单 / 算价格分"时。

## 输入
- 招标文件:项目目录内或用户指定路径。pdf 先转文本读取;若是扫描件读不出文字,**停下来向用户要可复制文本的版本,不要凭记忆或常识补内容**。
- 若同目录已有我方投标文件草稿,一并读取,自评时对照。

## 第一步:遍历招标文件,提取四类内容(逐页读,不要跳读)
1. **投标文件组成说明**:必须提交的全部文件(资格证明、授权书、保证金凭证、技术标、商务标、报价表…),含份数、正/副本、装订、密封、签章、电子标上传要求。
2. **报价/投标一览表要求**:格式、币种、含税与税率、大小写金额、分项报价要求、是否允许缺项漏项、报价有效期。
3. **星标项(★/▲)与废标条款**:逐条摘出。★/▲ 通常是"不满足即废标"的实质性条款;另外全文搜索"废标""无效标""否决投标""不予受理"等字样的条款。**一条都不能漏,这是本技能的生命线**。
4. **评分表**:所有评分项、分值、评分标准原文;**价格分公式单独原文记录**。

摘录规则:每条带出处(页码/条款号);长原文可压缩但不得改变含义;某类内容确实没有就写"招标文件中未见",不要编。

## 第二步:生成自检清单 xlsx
输出到项目目录:`projects/<项目>/06-投标自检_v1.xlsx`(python3 + openpyxl;计算用 Excel 公式,不要用 Python 算好硬写结果)。

| Sheet | 结构 |
|---|---|
| **组成与格式** | 序号 \| 类别(组成/报价格式) \| 招标要求(含出处) \| **是否满足(下拉:✓/✗/部分)** \| 责任人 \| 备注 |
| **星标与废标项** | 同上,行用浅红底提醒;表头注明"任一项 ✗ = 废标风险" |
| **评分自评** | 评分项 \| 分值 \| 评分标准(含出处) \| **我方自评分(蓝色输入)** \| 依据/差距说明;底部 `=SUM()` 总分与满分对比;价格分一行引用「价格自评」sheet 的我司得分(绿色跨表引用) |
| **价格自评** | 见第三步 |

样式沿用工作台惯例(与 04-毛利测算一致):蓝色=输入、黑色=公式、黄底=关键假设、Arial;打勾列用数据验证下拉。

## 第三步:价格自评 sheet(按招标文件的真实公式)
1. 把招标文件的**价格分公式原文**贴在 sheet 顶部,注明出处页码。
2. 输入区(蓝色):各投标厂商名称、报价,一行一家;**我司行高亮**。厂商数量可增删,公式范围要兜住。
3. 用 Excel 公式实现招标文件的真实算法。常见类型参考(仅当与招标原文一致时套用):
   - **最低价基准**:基准价 `=MIN(有效报价区)`;得分 `=基准价/我司报价×价格分值`
   - **平均价基准**:基准价 `=AVERAGE(报价区)×下浮系数`;报价偏离基准价每 ±1% 扣 x 分(ABS/ROUND 组合,注意扣完不为负 `=MAX(0,…)`)
   - **去高去低平均**:基准价 `=(SUM(区)-MAX(区)-MIN(区))/(家数-2)`(家数不足时的处理按招标文件)
4. 结果区:**每家厂商的得分都算出来**(知己知彼),我司得分加粗;下方附**报价敏感性小表**:我司报价 ±2%、±5% 时的得分变化。
5. 公式有歧义(如"下浮系数由评委现场抽取")→ 每个可能取值各算一列,标【待确认】。

## 铁律
- 招标文件的事实(条款、分值、公式)**不得编造或凭记忆补全**;没读到 = 【待补充】。
- **打勾列留空**,由用户自己勾;自评分可给建议值,但备注"建议值,待确认"。
- 完成后只输出:文件路径 + 星标/废标项条数 + 自评总分/满分 + 最明显的风险(≤3 条)。
